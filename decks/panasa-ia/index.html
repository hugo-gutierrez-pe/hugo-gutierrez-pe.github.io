¿Qué es la IA?

La IA es un condensador de relaciones

Una cliente dice a un arquitecto: "Quiero una casa amplia y ventilada para 5 personas."

La IA, entrenada con miles de estas conversaciones y planos, aprende relaciones:

"Amplia" → ventanas grandes
"5 personas" → 5 cuartos

La IA condensa relaciones pregunta→respuesta. No crea un Frank Gehry — produce una casa promedio, funcional, perdiendo detalles idiosincráticos.

Interacción

Todo entra como texto.
Todo sale como texto.

Los LLMs actuales solo procesan texto. Para trabajar con un Excel:

01

La IA lee el archivo como datos → lo convierte a texto

02

Escribe código Python que manipula el Excel

03

Ejecuta el código → genera un nuevo archivo Excel

04

Tú abres el resultado

No es nativo. La IA no "ve" celdas. Tiene "choques" con archivos complejos.

Gobernanza

Cuentas corporativas.
Zero-retention. Control de TI.

Cuentas corporativas — transferibles, auditables.
API keys bajo control de TI — rotación periódica.

Modelo 2-out-of-3: nunca acceso total sin control.
Ley N° 29733: Protección de Datos Personales (Perú).
ISO 27001: lineamientos de ciberseguridad.
